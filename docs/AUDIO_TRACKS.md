# Audio Tracks by Bank

[← Audio Replacement](AUDIO_REPLACEMENT.md)

Every track name available for [`momi/audio` replacement](AUDIO_REPLACEMENT.md),
organized by bank, generated from the actual game files with
[`tools/audio-replace`](../tools/audio-replace)'s `list` command - so you
don't have to run it yourself just to find a track name. Each entry is the
exact name to put in your manifest's `[...]` heading, with its current
duration.

`Master.strings.bank` isn't listed: it's a name/GUID lookup table, not an
audio bank, and has no replaceable tracks.

This snapshot is tied to the game build it was generated against and will
drift as the game updates - regenerate with `tools/audio-replace list` if a
track you're looking for isn't here, or looks wrong.
